# 釣り銭予測（単体デモ）

合計金額を入れるだけで、お客さんが出しそうな金額と、そのお釣りを一覧で先に出すWebアプリです。
同人誌即売会向けレジアプリ「どびん」の3本柱の1つ「釣り銭予測」を、単体で試せるように切り出したデモです。

## 使い方

`index.html` をブラウザで開くだけで動きます（サーバー不要、外部ライブラリなし）。
キーパッドで合計金額を入力すると、候補が自動で並びます。

## 予測の考え方

候補は次の3種類から作り、「お釣りの枚数が少ない順」に並べます。

1. **ぴったり**の金額
2. **各単位への切り上げ**（10円・50円・100円・500円・1,000円・2,000円・5,000円・10,000円）
3. **小銭を足した額**：お釣りが硬貨・紙幣1〜2枚で済むよう、あらかじめ小銭を足して出す払い方
   - 例：合計2,750円に **3,300円** を出すと、お釣りは550円（500円玉＋50円玉の2枚）
   - 3,000円ちょうどを出すより、お釣りの枚数が減ります
4. **紙幣＋端数の小銭**：紙幣に、合計の100円未満の端数ぶんの小銭を添えて出す払い方
   - 例：合計2,750円に **5,050円**（5,000円札＋50円玉）を出すと、お釣りは2,300円できりが良くなります

預かり金額を入力してからお釣りを計算するのではなく、先に候補を出すのがポイントです。
レジ係は、お客さんが実際に出した金額の行を見るだけでお釣りが分かります。
